# EPMA USB CREATOR — dependências Python
#
# ESTE PROJETO NÃO TEM DEPENDÊNCIAS DE TERCEIROS. Este arquivo existe
# deliberadamente vazio para tornar esse fato explícito e verificável por
# ferramentas de análise de composição (SCA), que de outra forma não conseguem
# distinguir "projeto sem dependências" de "projeto não analisado".
#
# O programa usa apenas a biblioteca padrão do Python:
#   argparse, atexit, base64, collections, contextlib, ctypes (só no macOS), errno,
#   filecmp, hashlib, http.client, inspect, json, logging, os, pathlib,
#   platform, plistlib, re, shutil, signal, subprocess, sys, tempfile, textwrap,
#   threading, time, traceback, urllib.error, urllib.parse, urllib.request,
#   webbrowser, zipfile, zlib e tkinter (interface gráfica; o modo linha de
#   comando não precisa dele).
#
# Requisito de interpretador: Python 3.10 ou superior.
#
# Tkinter faz parte da biblioteca padrão, mas em muitos sistemas é distribuído
# num pacote separado do sistema operacional (não via pip):
#   macOS:          brew install python-tk@<sua-versao>
#   Debian/Ubuntu:  sudo apt install python3-tk
#   Fedora:         sudo dnf install python3-tkinter
#   Arch:           sudo pacman -S tk
#   openSUSE:       sudo zypper install python3-tk
#
# As dependências de sistema (parted, rsync, wimlib etc.) estão documentadas
# no README.md e em SECURITY.md.
#
# ANTES DE ADICIONAR QUALQUER BIBLIOTECA AQUI: cada dependência adicionada passa
# a fazer parte permanente da superfície de ataque do projeto e precisará ser
# monitorada por vulnerabilidades. Ver SECURITY.md.
